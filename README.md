# 🎓 Tech Fest 2026 – College Event Poster

A modern and attractive **college event poster** designed using **Figma**. The poster was created for a fictional/college **Tech Fest 2026** event with a technology-focused visual theme.

## 📌 Project Overview

The Tech Fest 2026 poster is designed to promote a college technical event. It uses a purple-to-blue gradient background, coding-themed visuals, event information, a registration button, and college branding.

The design focuses on **visual hierarchy, contrast, alignment, consistency, and simplicity** to create an engaging and professional poster.

## 🎨 Design Details

- **Design Tool:** Figma
- **Frame:** A4
- **Dimensions:** 595 × 842 px
- **Orientation:** Portrait
- **Layout:** Single Layout
- **Alignment:** Center
- **Background:** Purple to Blue Gradient

## 🎨 Color System

- **Primary:** Purple
